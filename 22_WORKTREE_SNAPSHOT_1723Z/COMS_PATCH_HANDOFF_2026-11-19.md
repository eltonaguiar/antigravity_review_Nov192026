## 4. COMS changes, justification, and why

| Bug | Change | Why |
|---|---|---|
| **B1** send lies about delivery | `cmd_send` now `-q 1`, prints an honest note, adds `--retain` for messages that must outlive a sleeping listener | QoS 0 + no `-r` meant the broker acknowledged and discarded to zero subscribers; "sent" was not evidence of receipt |
| **B2** register blanks omitted fields | only emit `goal/todo/done/files/commits/prompt` when supplied (Linux python; Windows conditional `$obj`) | emitting all seven keys with `""` made a short update silently erase prior goal/files/commits |
| **B3** listen dies silently | supervised `while true; do mosquitto_sub …; sleep 5; done` reconnect loop (already upstream on Linux; added to Windows) | a broker restart/LAN blip made an agent permanently deaf with no error, indistinguishable from "no messages" |
| **B4** no non-blocking read | `COMS check --agent <role> [--wait N]` reads retained + in-flight without blocking forever (already upstream on Linux; added as a real verb on Windows) | `listen` blocks; agents had no way to answer "what arrived while I was away?" |
| **B5** secret regex false-positives | `(?i)(?<![?&])(api[_-]?key\|secret\|password\|passwd\|token)\s*[:=]\s*\S{8,}` | old pattern matched `?token=abcdefghij` in job URLs — exactly the payload this fleet pastes; lookbehind skips query-string params |
| **B6** duplicate seats | **NOT fixed** (documented gap) | needs a retained-registry uniqueness check on register; honour system today |
| **B7** slug rewrites dots | `resolve_topic()` slugifies `inbox/<host>/<worktree>/…` before publish; prints resolved topic | folder `findtorontoevents_antigravity.ca` subscribes as `…-ca`; sending the literal dotted name published into the void while printing "sent" |
| **B8** no unregister | `COMS unregister --agent <role>` clears retained registry (empty payload) + drops local jsonl row | `registry/#` retained + append-only jsonl grew forever with dead seats |
