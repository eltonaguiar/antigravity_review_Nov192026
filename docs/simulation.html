Following high-performing analysts — design + demo

What would happen if we took the latest endorsed picks from analysts with a measured track record? Below is the design, the data blocker, and a synthetic demo that exercises the pipeline end to end.

SYNTHETIC DEMO — every number in the table and cards is generated data, not real analysts. It exists to prove the mechanics, not performance.

1. The design

ELI5: First rank analysts by how often their Buy calls beat the market. Then, each month, take only the latest picks from analysts above your bar, buy them equal-weight at the next close, hold for the horizon, charge costs, and compare with the index.
  • Filters: minimum calls, minimum hit rate, horizon (30/90/180d), maximum age of the call, asset class.
  • Entry: first close after the published timestamp (no look-ahead).
  • Exit: horizon end, or the analyst’s next action if earlier.
  • Portfolio: equal weight, max N names, 6.7bp round-trip cost, benchmark = SPY.
  • Metrics: hit rate, mean excess, CAGR, vol, Sharpe, max drawdown, turnover, n.
  • Anti-overfit: rank analysts only on data before each decision date; report CPCV/DSR before any claim.

2. The data blocker (real)

Free feeds cannot rank analysts by name:

  • Yahoo upgrade history: 52 buy-ish actions / 37 firms / max n=4 over 540 days for 12 mega-caps.
  • Finnhub upgrade/downgrade: HTTP 403 (paid); FMP upgrades: HTTP 429 (quota).
  • Person-level success rates: Benzinga, TipRanks, LSEG I/B/E/S, FactSet, Bloomberg ANR — paid, equities only.

Until a licensed feed arrives, no real analyst-follow simulation can be published honestly. The demo below uses synthetic analysts.

4. What would make it real

  • A licensed per-analyst actions feed (Benzinga/TipRanks/LSEG) with a stable analyst ID.
  • Point-in-time prices and a benchmark; corporate actions; FX for non-USD.
  • Forward-only evaluation: freeze the rule, then accumulate n≥100 independent picks.
