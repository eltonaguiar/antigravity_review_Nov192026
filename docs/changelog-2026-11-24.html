Key benefits and top achievements

Read this first. The programme's benefit is not a return. It is that every number below names what it divides by, every correction is published as prominently as the result it replaced, and no gate was ever moved to let a candidate pass. Capital deployed: $0. Nothing here is a claim of edge, profit, class ranking or skill — three of those were tested and withdrawn.

What the programme is actually good for

  • Denominator discipline. Each figure states the row count it divides by. The per-class ranking was withdrawn precisely because it did not.
  • Corrections at equal weight. Withdrawn results, refuted units errors and our own wrong claims appear beside the findings, not in a footnote.
  • No gate lowered. No threshold was moved to pass a candidate; a clean null is an accepted outcome.
  • Adversarial review. Independent model families and a pre-publication overclaim guard were used as critics, with our own numbers withheld from them so they had to supply their own reasoning.

Corrections — two claims from today, withdrawn

  • 2026-11-24 · withdrawn "mde_pct 18.868 implies σ = 209% — a units error"

    Wrong. The code computes mde = 2·sd·√(n_symbols/n); inverting with n=963 and n_symbols=485 gives sd = 13.29%, entirely ordinary for single-stock returns. The figure is internally consistent. What survives is narrower: 18.868% is the single-symbol MDE and is 22× (√485) the bucket-mean MDE of 0.857%. The difference MDEs are 2.35 / 2.78 / 2.15%, and the observed differences of 1.21 / 1.60 / 0.39 pp all fall below them — so UNDERDETERMINED survives on the difference MDEs, not on any units error.

What replaces it

  1. Publish the backfill share beside every per-class statistic.
  2. Restrict the comparison to live-resolver rows only and report n after that filter — for most classes that is 2–4% of rows, which is the honest sample.
  3. Report the two-table disagreement rate and both means; publish no single figure while they disagree in sign.
  4. Recompute the 1,664 from exit_price / entry_price instead of copying a zero.
  5. Flag the 2,906 unjoined rows as an explicit upward bias rather than dropping them silently.

    1. The role filter is dead code. Lines 117–119 parse is_officer, is_director and is_ten_percent_owner — and excess(code) never reads them. It takes only the code string and iterates every event of that code. So the headline excess is computed over all open-market purchases, including 10% owners and entities, and is not the insider signal the brief specified.
    2. The flag parser counts 1 of 20. (r.get("is_officer") or "").lower() == "true" is a literal match, but the CSV stores 1 and true. Measured on the purchase rows: values are {'0': 23, '1': 19, 'false': 9, 'true': 1} — so the literal test finds 1 officer row where a truthy test finds 20.

Coverage critique

Replaced the claim that reporting coverage fixes comparability with the measured confound: coverage spans 0.010 to 0.750 — a 75× ratio — and is almost perfectly aligned with class. On CRYPTO, 12,730 of the 16,360 rows stored with the exact uppercase label CRYPTO are backfilled (77.8% of those 16,360); those same 12,730 rows are 33.3% of all 38,218 CRYPTO rows. Both are true of the same 12,730 rows. Across the whole table, 37,115 of 63,792 rows (58.2%) are backfilled. Disclosure is necessary, not sufficient.

Backfill is confounded with label case, not asset class. All 12,730 backfilled CRYPTO rows carry the uppercase label CRYPTO, while all 21,858 lowercase crypto rows are live. Storage case therefore predicts resolver path perfectly, so any case-based split is a resolver split, not a class comparison.

Dilution sensitivity

Replaced any use of a coverage-scaled mean as a corrected estimate with an explicit MAR-dependent bound: FOREX moves from +0.0563% to +0.3066% and COMMODITY from −0.1032% to −0.6583%. Missingness is not random — unjoined rows average −0.0828 versus −0.0435 for joined rows — so the bound must not be ranked or quoted as a mean.

Two-table reconciliation

Replaced unverified COALESCE of the two PnL columns with the measurement: 1,263 of 7,945 overlapping rows disagree (15.9%), largest gap 187.18 pp, and the means have opposite signs (−0.0929% at_pick vs +0.0172% trading).
