# Breadth report -- analyst-action collection (PREREG section 0)

zoo-savant, 2026-11-24. Generated by `collect_analyst_history.py`, then `--report`.

## How to reproduce

```bash
cd 42_HARVEST_UPGRADE_2026-11-24/tracker
python3 collect_analyst_history.py --symbol-file sp120.txt --out analyst_actions.csv
python3 collect_analyst_history.py --report --out analyst_actions.csv
```

`sp120.txt` holds 155 US large/mid-cap tickers across all 11 sectors (the file name
predates the final list size). The raw `analyst_actions.csv` is NOT committed -- it is
70,233 rows and regenerable; this summary is the record.

## Result

- 70,233 action rows, **153 tickers** resolved of 155 requested, **237 firms**.
- **Firms reaching each floor: 300 = 22, 500 = 8, 750 = 1.**
- Baseline for comparison: on 30 mega-caps, **ZERO** firms reached 300.

Breadth, not history length, was the binding constraint, as PREREG section 0 predicted:
a firm generates ~5 changes per ticker it covers, so ~150 tickers is what lifts the
best firm from 234 to 825 changes.
