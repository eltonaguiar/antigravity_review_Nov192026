# Calibration matched-benchmark spec

zoo-savant, 2026-11-25. For the SPY gate-2 defect (a single index is not a
characteristic match). `class_calibration.md` is NOT edited and no gate is lowered.

## Part 1 -- the construction rule (frozen before any run)

**Size proxy:** 60-day mean dollar volume (close x volume), NOT market cap -- it measures
tradeable liquidity, which is what a capacity-matched control needs, and it is available
for every symbol without fundamentals.

**Momentum window:** 126 trading days (6 months), `close[-1]/close[-127] - 1`, computed on the
same price source and adjusted closes as the calibration.

**Terciles:** within the 485 symbols that have at least one included event, cut at the
one-third and two-third quantiles. Measured cutoffs:

- 60-day dollar volume: LOW <= $274,939,613 < MID <= $568,359,427 < HIGH
- 126-day momentum:    LOW <= -0.0000 < MID <= 0.1000 < HIGH

**Date alignment rule:** a symbol's size and momentum are assigned from data up to and
including its FIRST included event's entry date, and that assignment is held fixed for all
of its events (no re-estimation per event, which would let the assignment drift with the
outcome). The control for an event is the mean return of events in the same (size, momentum)
cell, computed LEAVE-ONE-OUT and excluding the event's own symbol.

## Part 3 -- what this changes about the SPY gate-2 verdict

It makes gate 2 *answerable* rather than passed. SPY as a single index could not be called a
characteristic match, so the verdict was UNMET; with a size-and-momentum matched control the
benchmark is now defined by a rule that was frozen in advance and covers every included event.
What it does NOT change: the matched-benchmark rho has not been re-run here, so the inverted
sign (rho -0.0467, permutation p 0.9995 under SPY) still stands only as a SPY result until the
control is actually executed; and matching on two characteristics does not make it a full
factor model -- sector and beta remain unmatched, which should be stated in any write-up.
